# Characters

Generated by `tools/assets/characters/` (see the README there for how to rebuild). Units metres, +Y up, characters face +Z, feet at y = 0, rest pose = MakeHuman A-pose. All character files share **one skeleton (63 bones)** with identical bone names and rest pose; `anims_humanoid.glb` carries the same skeleton plus every clip, so a single `THREE.AnimationMixer` clip set drives every character by bone name.

Each character GLB holds one skinned mesh per LOD with these primitives/materials (draw calls): `skin`, `eyes`, `hair`, `cloth` (wool garments, double-sided), `gear` (webbing/leather/boots/brass) and `helmet` (where worn). LOD1 reuses the LOD0 materials/textures.

## Skeleton (63 bones)

`root` (origin, never animated) > `hips` > `spine05..spine01` > `neck01`, `neck02`, `head`, `jaw`; per side `pelvis`, `upperleg01/02`, `lowerleg01/02`, `foot`, `toes`; `clavicle`, `shoulder01`, `upperarm01/02`, `lowerarm01/02` (twist bones), `wrist`, fingers `finger1-1..3` (thumb), `finger2` (index), `finger3` (middle), `finger4` (ring + little finger merged). Dropped MakeHuman bones (face, toes, breast, metacarpals, little finger, neck03, eyes) were merged into their kept ancestor (little finger into the ring chain). Only `hips` has a translation track that varies.

## Textures

Embedded JPEG (quality 85-90), PBR metal/rough with separate occlusion (ORM: R = AO, G = roughness, B = metalness), tangent-space normal maps (OpenGL +Y). Per character: skin 1024² (albedo, normal, ORM), cloth 1024² (albedo, normal, ORM), gear 1024² albedo/normal + 512² ORM, helmet 512², hair 512² (ORM 256²), eyes 256² albedo (+128² ORM). fp_arms: skin and sleeve 1024² (ORM 512²), device 256², screen 256² emissive, paper 128². All textures are procedural own work.
